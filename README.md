One line, 93 characters, built around a borrowed idiom that gets its emergency swapped out: the thing behind the glass is a yearbook, and the thing it puts out is confidence. The joke is the last three words, so nothing before them explains anything. `main.py` reads `entry.txt`, strips the trailing newline, and writes the bare line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) — stdlib only, no clock, no randomness, identical bytes every run.

## Run it

```sh
python3 main.py
```
